Platform-Key LLM Calls That Do Not Charge the Wallet

Every LLM call site that picks its API key from the platform .env (process.env / serverEnv) and never deducts from any wallet. These are the calls the platform pays for directly, with zero wallet recovery.

12 unbilled call sites Companion to llm-billing-audit.md Verified 2026-06-01 Repo: AgentKong_App

A Inclusion criteria

A call site appears here only if both are true:

  • 1 · Key source = platform — instantiated with process.env.*_API_KEY or serverEnv.*_API_KEY, not a business/agency key resolved via openai-key-resolver.ts / openai-key.service.ts.
  • 2 · No wallet charge — the path never calls deductCredit, deductBalance, or agentMessageCharge.
